# Hello World

欢迎来到我的博客！这是我使用Astro搭建的第一个博客文章。

## 关于这个博客

这个博客使用了以下技术栈：

- **Astro** - 现代化的静态网站生成器
- **TypeScript** - 类型安全的JavaScript超集
- **CSS Grid** - 灵活的响应式布局系统
- **Markdown** - 简洁的内容编写格式
- **GitHub Pages** - 免费的网站托管服务

## 为什么选择Astro？

Astro有以下几个优点：

1. **快速性能** - 只发送必要的JavaScript到浏览器
2. **组件灵活性** - 支持React、Vue、Svelte等多种框架组件
3. **内容优先** - 优秀的Markdown支持和内容管理能力
4. **现代化开发体验** - 支持TypeScript、自动重载等功能
